# 旅灯镇 — 设计简报

## Title & 10-second pitch

**旅灯镇 / Wayfarer Lantern Town**

从海风里醒来，沿灯火走进 Young 的个人主页；北边那座洞穴，是唯一一场真正的冒险。

## 立意

普通个人主页把人压成一列链接。旅灯镇把“认识一个人”恢复成探索：先看见他选择怎样布置一座镇，再决定推开哪扇门。地图不是装饰，而是信息架构本身。

## 主世界核心循环

沿路探索 → 发现地标 → 交互阅读或启程 → 回到镇上继续闲逛。

## 冒险洞穴核心循环

进入房间 → 战斗或解谜 → 收集三枚旅灯碎片 → 击败守门者 → 点亮出口。

## Retention loop

- 主世界记住最后位置、BGM、音量与静音设置。
- 地牢独立保存检查点、最佳用时、已取得碎片和通关次数。
- 数据驱动的游戏目录与房间配置允许未来增加站内游戏或外链游戏，无需改写主世界。

## 惊呼 moment

进入小镇时，深蓝像素幕布从中央分开，海浪声和码头灯依次亮起；角色直接站在船边，远处小镇道路成为自然的视觉引导。

## 内行落泪 depth

- 所有链接在世界里都有空间语义：知识在图书馆，兴趣留在海滩，外链从码头启程。
- NPC 会循环说静态台词，被攻击时只抛出受击梗，不掉血、不反击。
- 地牢的三枚旅灯碎片分别对应观察、判断和实现，收集顺序自由，最终战会根据遗漏碎片改变提示。

## Art & audio direction

唯一素材家族：Ninja Adventure Asset Pack（Pixel-Boy 与 AAA，CC0 1.0）。

色板：

- `Harbor Ink #172638` — 幕布、夜色、深层面板
- `Moss Path #55924B` — 草地、成功状态
- `Lantern Leaf #A8CF45` — 路标、焦点与交互提示
- `Sunlit Sand #F3BD6A` — 道路、纸张和主按钮
- `Dock Coral #E76F51` — 攻击、Boss 与高优先级提示
- `Tide Blue #48A9C5` — 海水、链接与音乐状态

字体：NinjaAdventure 用于短标题、数值和按钮；中文正文使用系统黑体。像素字体不承担长段落。

光源：镇上由暖色灯笼从道路边缘向内照亮；森林和洞穴保持偏蓝绿色。音乐只使用素材包内的 OGG。

## Layout signature

主世界的地图本身就是站点导航。内容页沿用“旅行日志”结构：页面左侧是一条由码头印章、书页签和贝壳标签组成的纵向旅程线，而非通用卡片网格。

## Scope guard

第一版只打磨两件事：可探索的个人主页主世界，以及一个完整的独立地牢。

不包含钓鱼、账号、云存档、排行榜、联机、访问者上传、项目工坊、展览馆、动态告示板、多款站内游戏或跨游戏进度同步。
