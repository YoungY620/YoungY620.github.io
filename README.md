# Young E. — Personal Page

A minimal, responsive personal page for [youngy620.github.io](https://youngy620.github.io/).

The site is plain HTML, CSS, and JavaScript with no build step or third-party runtime dependencies. Every push to `main` is deployed automatically by GitHub Actions.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
