# 冒险洞穴：旅灯试炼

版本：1.0.0

## 10 秒介绍

在七个相互独立的房间里完成灯序、路线选择、双向潮汐机关、宝库守望、守灯与三阶段 Boss 战，带回三枚旅灯碎片。

## 立意与核心循环

洞穴是个人主页主世界中的唯一站内游戏。它把“观察、选择、实现”做成三枚可取得的碎片，并让玩家通过不同类型的试炼逐步理解规则。

核心循环：观察房间 → 完成机关或持续战斗目标 → 恢复与记录检查点 → 进入下一房。

## 玩法结构

- 门槛之间：两轮持续教学，学习移动、攻击与冲刺。
- 回声长廊：三套逐渐变长的灯序，每套之后有不同伏击。
- 分岔画廊：观察与勇气两条路线，各有三段不同敌人组合。
- 潮汐工坊：两套四块压力板顺序，以及横向、纵向潮刃。
- 守望者宝库：三段守望，最后主动开启宝箱取得第二枚碎片。
- 旅灯圣所：三轮计时守灯；敌人会直接攻击中央旅灯。
- 最后门庭：Boss 三阶段，两次结界期必须持续清理援军。

检查点位于潮汐工坊后和旅灯圣所后。存档、最佳时间、通关次数、声音与语言设置均保存在 localStorage。

## 美术、动画与音频

唯一素材家族为 [Ninja Adventure Asset Pack](https://pixel-boy.itch.io/ninja-adventure-asset-pack)，作者 Pixel-Boy 与 AAA，CC0 1.0。

蓝忍者源图与 [官方参考项目](https://github.com/pixel-boy/NinjaAdventure) 的 `content/character/ninja_blue/sprite.png` 字节一致。角色动画直接沿用官方规则：方向列为下、上、左、右；待机第 0 行；行走第 0～3 行；攻击第 4 行；6 FPS。16px 原帧以整数倍绘制并关闭平滑采样。

## 本地运行

在仓库根目录运行：

```bash
npm install
npm run dev
```

生产构建与完整校验：

```bash
npm run check
```

地牢是独立入口 `/games/dungeon-one/`，但复用根项目的 `src/i18n/`、`src/shared/ninja-animations.ts` 和 `public/assets/ninja-v1/`。
